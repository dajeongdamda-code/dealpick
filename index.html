DealPick Video Publisher · Windows desktop

상품 사진에서 숏폼 영상까지,
오늘의 득템픽

상품 상세페이지의 실제 원본 이미지를 사용자가 선별해 세로형 숏폼 동영상을 만들고, 확인 후 연결한 SNS 계정에 게시할 수 있도록 돕는 Windows 기반 프로그램입니다.

개발·테스트 진행 중 · 별도 공개 다운로드 미제공

주요 기능

📷 상품 원본 사진

연결된 쇼핑 페이지에서 가져온 이미지 후보를 직접 검토하고 선택합니다. 원본과 분할 장면을 구분하여 관리합니다.

🎬 숏폼 영상 제작

긴 상세 이미지 분할, 사진 선택, AI 음성·자막, 가격 표시 등을 이용해 세로형 MP4를 제작합니다.

📤 SNS 게시 연결

게시 전 상품 정보·사용권·광고 고지를 검토하고, 승인된 계정 권한으로 각 플랫폼에 영상 전송을 요청합니다.

사용 흐름

01 · 자료 확인

상품 사진과 현재 판매 정보, 재사용 권한을 확인합니다.

02 · 영상 검토

짧은 광고 대본, 사진 장면, 자막, 음성, 가격 표시를 검토해 MP4를 만듭니다.

03 · 게시 승인

연결한 SNS 서비스의 계정과 공개 범위를 확인한 후 전송을 요청합니다. 서비스별 심사 및 승인 조건이 적용됩니다.

운영·지원 안내

DealPick은 현재 개인 개발·테스트 중인 Windows 데스크톱 소프트웨어입니다. 공개 회원가입, 유료 결제, 불특정 다수 대상 서비스 제공은 현재 운영하지 않습니다. 플랫폼별 공식 API 승인 여부에 따라 기능이 제한될 수 있습니다.
