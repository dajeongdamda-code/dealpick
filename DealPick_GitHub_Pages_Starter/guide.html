DealPick 사용 안내

Windows 데스크톱 프로그램의 현재 개발·테스트 중인 작업 흐름입니다.

1. 상품 자료 확인

브라우저 확장 기능과 연결해 상품 이미지 후보를 살피고 광고에 필요한 원본만 선택합니다. 가격은 공식 판매페이지에서 확인한 값만 사용하고, 변동 가능한 가격은 게시 전에 재확인합니다.

2. 동영상 제작

원본 이미지에서 세로로 긴 상세페이지를 분할하고 장면을 선택합니다. 사용자가 확인한 정보로 자막·음성·구매 안내를 구성해 세로형 MP4로 출력합니다.

3. SNS 연결 및 게시

YouTube, Instagram 및 TikTok API 연결은 각 서비스의 OAuth 인증·게시 권한 및 개발자 앱 심사에 따릅니다. 사용자 승인 및 게시 전 검토 후 전송을 요청하며, 실제 업로드 완료 여부는 각 플랫폼에서 확인합니다.

4. 사용 권한과 제휴 광고

상품 사진의 광고 재사용 권한, 상품 구성, 가격, 제휴 링크 고지 등은 게시자가 확인해야 합니다. 공식 판매페이지의 사진을 사용한다고 해서 광고 이용 권한이 자동으로 발생하는 것은 아닙니다.
