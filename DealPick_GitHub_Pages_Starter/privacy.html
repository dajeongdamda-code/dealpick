개인정보처리방침

적용일: 2026년 11월 6일 · 운영 주체: [[실제_운영자_또는_사업자_명칭]]

게시 전 실제 구현과 일치하는지 확인해야 하는 초안입니다. 특히 토큰 저장 위치·외부 API 전송·데이터 삭제 정책·문의처를 점검하세요.

1. 적용 범위

본 방침은 DealPick 공식 안내 웹사이트 및 Windows 데스크톱 프로그램의 데이터 처리 안내를 목적으로 합니다. 이 안내 웹사이트에는 별도의 회원가입 및 업로드 양식이 없습니다.

2. 처리될 수 있는 정보

프로그램 이용 과정에서 사용자가 직접 입력한 상품 정보, 선택한 사진과 제작 영상, 게시 메타데이터, 외부 플랫폼 연결을 위해 승인한 OAuth 토큰 및 계정 식별자, 업로드 시도 결과 등이 처리될 수 있습니다. 연결 권한은 사용자가 각 플랫폼에서 직접 허용한 범위에 따릅니다.

3. 처리 목적 및 보관

영상 생성, 게시 대상 확인, 플랫폼에 게시 요청 전달, 중복 전송 방지, 연결 상태 및 작업 기록 제공을 위해 데이터를 사용합니다. 현재 데스크톱 프로그램의 설정·계정 연동 정보는 주로 사용자 PC의 로컬 파일에 저장됩니다. 사용 중인 선택적 외부 AI 서비스가 있다면 해당 서비스의 정책도 적용될 수 있습니다.

4. 외부 서비스 전송

사용자의 승인과 게시 요청에 따라 동영상, 제목, 설명 등 게시에 필요한 정보가 YouTube(Google), Instagram(Meta), TikTok 등에 전달될 수 있습니다. 서비스별 토큰 발급 및 데이터 이용에는 각 플랫폼의 개인정보처리방침이 적용됩니다.

5. 이용자 선택과 데이터 삭제

사용자는 연결된 각 SNS 계정의 앱 권한을 해제할 수 있습니다. PC 로컬 데이터의 정리 또는 데이터 삭제 지원이 필요한 경우 아래 문의처로 연락할 수 있습니다. 로컬 파일을 삭제하기 전 필요한 사진·영상·설정을 백업할 것을 권장합니다.

6. 웹사이트 운영

본 안내 사이트는 GitHub Pages에서 제공됩니다. 별도 자체 방문 추적 스크립트나 회원가입 폼은 포함하지 않았습니다. 호스팅 제공자의 서버 로그 등은 GitHub 정책에 따를 수 있습니다.
